# Prompt Sample

本リポジトリでは，Pythonのプロジェクトに対応したコード支援系AIに渡すプロンプトの例を掲載する．

## ディレクトリ構成

```
本リポジトリ
│
├─ common.md # コード支援系AIに渡す各プロジェクト共通のプロンプト
│
├─ prompt.md # コード支援系AIに渡す各プロジェクト固有のプロンプトのメモ
│
├─ LICENSE   # ライセンスファイル
│
├─ README.md # 本ファイル
│
```

## プロンプトの渡し方

1. 本リポジトリのcommon.mdとprompt.mdをコピーし，プロジェクトディレクトリに配置する

2. 下記の編集前prompt.mdを，編集後prompt.mdのように編集する

- 編集前

~~~
# <ここにプロジェクト名を記述する>

## 最初のプロンプト

```
<ここにAIに渡すプロンプトを記述する>
```
~~~

- 編集後

~~~
# Prompt Sample

## 最初のプロンプト

```
`common.md`に従ってプログラムの実装やレポートの作成，GitHubへの掲載準備を行ってください．
本プロジェクトでは，本ディレクトリ内のファイルを確認し，GitHubに掲載するための`README.md`を作成してください．
```
~~~

3. prompt.mdに記載したプロンプトをコピーし，コード支援系AIに渡す

4. コード支援系AIがcommon.mdに従ってプログラムを作成し，プロンプトで渡されたタスクを行う
